## Projeto Final
O banco de dados **"rh_analise"** foi criado para facilitar o gerenciamento de informações sobre funcionários, cargos, salários, departamentos e desligamentos dentro da Fictícia. Seu objetivo principal é fornecer insights sobre a rotatividade de funcionários, histórico salarial e estrutura organizacional.

A tabela **`funcionarios`** contém os dados pessoais e históricos de admissão e desligamento. A tabela **`salarios`** registra os valores e períodos de remuneração de cada funcionário. A estrutura organizacional é representada pelas tabelas **`cargos`** e **`departamentos`**, que relacionam os funcionários às suas respectivas áreas. Por fim, a tabela **`motivos_demissao`** documenta as razões dos desligamentos, permitindo análises sobre a saída de colaboradores.
